# Validador de Comissão

Programa para o colaborador conferir a remuneração variável. Ele cruza o **extrato do parceiro** com o **analítico do colaborador** e lista as vendas que o parceiro recebeu e o colaborador não, pela **data da venda**. Também mostra quanto essas vendas mudam o atingimento e a RV.

## Como usar

1. Abra o link do programa.
2. Escolha o **canal** e o **seu perfil**.
3. Adicione os arquivos (.xlsx ou .csv):
   - extrato do parceiro;
   - analítico do colaborador (pode ser de mais de um mês de referência);
   - planilha de meta (opcional).
4. Escolha o **mês da venda**.
5. Confira a lista. **Contestar** vai para contestação (prazo de 15 dias). **Conferir** pede o analítico do mês em que o parceiro recebeu.
6. Use **Baixar Excel** ou **Copiar para Excel** para levar a lista para a contestação.

## Privacidade

Os arquivos são lidos no próprio navegador. Nada é enviado a servidor, e o GitHub só hospeda o programa, nunca os dados.
